= Introduction

This is a stub of the documentation for the "form content elements" (FCE) editor.

== Form Content Elements vs Form Engine

General
- The main feature of FCE is to offer data binding for A12 (input) widgets
- In addition, it offers closely related functionality like validation message boxes
- For all data access and mutation, including validation and computation, FCE relies on the separate component "simple data graph"

Specific
- In FCE, you first select the A12 input widget you want to use. Only then do you configure data binding and other settings.
